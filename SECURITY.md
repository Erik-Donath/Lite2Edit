# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Email [github@erikdonath.de](mailto:github@erikdonath.de) with a description, impact, affected versions, and reproducible details. Do not include secrets or unrelated personal information.

The maintainer will acknowledge the report and coordinate a fix and disclosure with the reporter. Please allow time for investigation before publicly disclosing an unpatched issue.

Security fixes are provided for the latest release where practical. Older releases may not receive fixes.
